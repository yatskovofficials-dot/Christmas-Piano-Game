# Christmas Piano Rhythm

Новогодняя игра-пианино с ритм-режимом для GitHub Pages.

## Как открыть (важно!)

### Вариант 1 — GitHub Pages (рекомендуется)
1. Создай репозиторий на GitHub
2. Загрузи все файлы
3. Settings → Pages → Source: Deploy from branch → `main` / root
4. Открой ссылку вида `https://username.github.io/repo-name/`

### Вариант 2 — Локально
```bash
cd christmas-piano-game
python3 -m http.server 8080
```
Открой в браузере: http://localhost:8080

**Не открывай index.html двойным кликом** — стили могут не загрузиться.  
Сейчас `index.html` самодостаточный (CSS и JS внутри), поэтому в большинстве браузеров работает и напрямую.

## Управление

| Клавиши | Действие |
|---------|----------|
| Q W E R T Y U | Белые клавиши (октава C4) |
| 2 3 5 6 7 | Чёрные клавиши |
| Z X C V B N M | Нижняя октава |
| I O P [ ] | Верхняя октава |
| ПРОБЕЛ | Старт / Пауза |
| Esc | Стоп |

## Кнопки в ритм-режиме
- **Пауза** — остановить / продолжить
- **Повтор** — начать песню заново
- **Стоп** — закончить и вернуться в меню

После окончания песни счёт сбрасывается — выбери новую мелодию или нажми «Ещё раз».

## Свои мелодии
JSON-файл:
```json
{
  "title": "Моя песня",
  "notes": [
    { "time": 0.0, "note": "C4", "duration": 0.5 },
    { "time": 0.5, "note": "E4", "duration": 0.5 }
  ]
}
```
